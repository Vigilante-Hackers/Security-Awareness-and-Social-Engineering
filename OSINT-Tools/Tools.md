# Tools for OSINT and Social Engineering  

This document provides a categorized list of tools for **Open-Source Intelligence (OSINT)** gathering and **Social Engineering** simulations. These tools are intended for ethical and educational purposes only.

---

## 🕵️ OSINT Tools  

### 1. **Reconnaissance Tools**
- **[theHarvester](https://github.com/laramies/theHarvester)**  
  Collects email addresses, subdomains, IPs, and more using public sources like search engines and APIs.  
- **[Recon-ng](https://github.com/lanmaster53/recon-ng)**  
  A full-featured web reconnaissance framework with built-in modules for OSINT gathering.  
- **[Spiderfoot](https://github.com/smicallef/spiderfoot)**  
  Automates OSINT gathering with a wide range of modules, including DNS, WHOIS, and social media.  
- **[OSINT Framework](https://osintframework.com)**  
  A collection of OSINT tools and techniques organized in a web-based framework.  

### 2. **Social Media and Profile Analysis**
- **[Maltego](https://www.maltego.com)**  
  A powerful tool for mapping relationships and analyzing social networks.  
- **[Twint](https://github.com/twintproject/twint)**  
  A Twitter scraping tool that doesn't require API keys.  
- **[Sherlock](https://github.com/sherlock-project/sherlock)**  
  Finds usernames across various social networks.  

### 3. **Metadata and Document Analysis**
- **[ExifTool](https://exiftool.org)**  
  Extracts metadata from images, documents, and other files.  
- **[FOCA](https://github.com/ElevenPaths/FOCA)**  
  Extracts metadata and hidden information from documents found online.  

### 4. **Network and Infrastructure Discovery**
- **[Shodan](https://www.shodan.io)**  
  A search engine for finding exposed devices and services connected to the internet.  
- **[Censys](https://censys.io)**  
  Provides insights into internet-facing devices and networks.  
- **[Amass](https://github.com/OWASP/Amass)**  
  Performs in-depth DNS enumeration and infrastructure mapping.

## 🎭 Social Engineering Tools  

### 1. **Phishing Simulation**
- **[PhishTank](https://phish tank.com)**
A database of phishing sites and a tool for simulating phishing attacks.
- **[Zphisher](https://github.com/htr-tech/zphisher)**  
    A versatile phishing tool that supports simulations for various social media platforms.
- **[Evilginx2](https://github.com/kgretzky/evilginx2)**  
  A man-in-the-middle attack framework for testing phishing and token interception.  

### 2. **Vishing and Pretexting**
- **[SpoofCard](https://www.spoofcard.com)**  
  Allows for phone number spoofing for ethical social engineering simulations.  
- **[VoiceChanger.io](https://voicechanger.io)**  
  Provides tools to alter voice tones during vishing tests.  

### 3. **USB and Baiting Tools**
- **[USB Rubber Ducky](https://shop.hak5.org/products/usb-rubber-ducky)**  
  A keystroke injection tool for simulating USB-based attacks.  
- **[Hak5 Bash Bunny](https://shop.hak5.org/products/bash-bunny)**  
  A multi-function USB attack device.  

### 4. **General Testing Frameworks**
- **[Metasploit Framework](https://www.metasploit.com)**  
  A penetration testing framework that includes social engineering modules.  
- **[Cobalt Strike](https://www.cobaltstrike.com)**  
  An advanced red teaming tool with phishing and payload delivery capabilities.

- **[PowerShell](https://docs.microsoft.com/en-us/powershell/)**
